# IMPACTONE V3.9

本次仅修正：
1. 题头 Skyline：直接使用用户确认样本提取的建筑线稿，保持原比例，不再重画、不再非等比拉伸。
2. 分享卡片：在 Vercel Preview 环境下，系统分享优先使用 canonical 的公开 impactone.news URL，避免把 Protected Deployment URL 分享到微信。
3. 微信按钮：恢复为直接调用 `weixin://` 打开微信客户端；不复制链接、不调用系统分享。
4. 系统分享按钮仍使用 Web Share API，可在手机系统分享面板中选择微信并携带文章 URL。
5. 订阅、收藏、评论、字号小/中/大、今日扫描折叠及底部固定栏均保持不变。

说明：网页标准没有“直接指定微信好友并自动带入网页卡片”的开放 API。`weixin://` 只能负责打开微信客户端；真正携带网页 URL 的可靠方式仍是手机“系统分享 → 微信”。
