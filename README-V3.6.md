# IMPACTONE V3.6

本次仅针对已确认的问题修正：

- 按样本重新绘制题头纽约 Skyline，帝国大厦改为细长、阶梯式顶部和长尖塔，并恢复右侧交叉弧线。
- 字号“小 / 中 / 大”继续保留并增强可见性；选择会由 localStorage 记忆。
- 首条新闻使用新的高分辨率 `images/daily/sample-oil-hd.jpg`，减少网页放大时的模糊。
- 今日扫描保持“标题 → 展开正文 → 正文 → 快评”的顺序。
- 手机转发继续优先调用系统分享，可从系统分享中选择微信。
- 电脑端点击“微信”改为复制当前文章链接并提示“请打开微信粘贴发送”，不再调用 `weixin://`，因此不会再出现浏览器“要打开 WeChat 吗？”确认框。
- 订阅、收藏、评论及底部固定栏逻辑不变。
