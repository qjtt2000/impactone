# 每日必读分享卡片

全球版和纽约版在发布当天 HTML 前运行：

```sh
python -m pip install Pillow
python scripts/prepare-daily-share.py daily/YYYY-MM-DD.html daily/YYYY-MM-DD-ny.html
```

脚本从各版第一条焦点新闻提取配图，生成 600×600 JPEG 缩略图，并用四条焦点新闻标题生成卡片摘要。提交两版 HTML 和新生成的两张 JPEG。发布后检查正式网页与缩略图，使用当期链接查看微信收件端卡片。企业微信后台若单独设置了封面或摘要，也使用当期图片和标题。

生成脚本还会写入两版 `share/YYYY-MM-DD*.html`，发布时一并提交。企业微信群发助手可测试使用这个地址。该页的首张可见图片和摘要直接来自当天焦点，读者可点图或「阅读本期全文」进入正文。

总编2026年11月18日补充：分享卡片摘要采用当期四条焦点标题，不固定为前三条；顺序跟随最终稿，缩略图采用当天焦点一照片，不使用品牌封面与固定宣传语。更新网站转发入口时，应读取当期摘要与分享地址。提交两版正文、两版share入口和两张JPEG缩略图。企业微信群发助手如提供独立标题、摘要、封面字段，使用同一组当期信息。未经实际查看企微客户端卡片，不得声称企微收件端已经实测通过。
