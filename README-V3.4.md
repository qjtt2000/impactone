# IMPACTONE V3.4

This update changes only the approved items:

- Rebuilt the cover NYC skyline to match the supplied sample more closely, with a slimmer/taller Empire State Building positioned farther right and a lower irregular skyline.
- Mobile/tablet share now calls the operating-system share sheet first. If WeChat is installed and exposed by iOS/Android, it can be selected there. No WeChat Official Account is required for this sharing flow.
- Desktop/non-supporting browsers keep the custom Facebook / X / LinkedIn / WhatsApp / Email / copy-link share center.
- Removed the misleading standalone WeChat button / Official Account JS-SDK hint from the share modal.
- Subscribe, favorite, comments, footer, and fixed bottom action-bar behavior are unchanged.
