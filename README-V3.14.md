# IMPACTONE V3.14

本版基于 V3.13，仅更新本轮确认项目：

1. 页头移除图形 Logo，恢复为样本中的纯文字 `IMPACTONE`。
2. 页脚“出品｜IMPACTONE”上方 Logo 更换为本轮上传的官方 Logo 原图。
3. 第一条焦点新闻油井图片更换为本轮上传的高清原图，不再使用旧放大版本。
4. PWA 桌面图标重新由官方 Logo 原图生成 192/512 图标。
5. iPhone/Android 安装到桌面后，从桌面图标首次打开时，如果通知权限仍为 default，会显示站内提示“接收《每日必读》更新通知 / 开启”。只有用户点“开启”后才调用系统通知授权框，符合浏览器权限规则。
6. 用户点 × 可暂时关闭站内通知提示；系统通知被允许或拒绝后不再重复弹该站内提示。
7. Service Worker 缓存版本升级，避免手机继续读取 V3.13 旧资源。

注意：当前已经完成通知授权和 Push Subscription 前端接口，但真正的“每天发布后自动推送”仍需要后端 VAPID/Push endpoint 接入。
