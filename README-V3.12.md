# IMPACTONE V3.12

本版在 V3.11 基础上更新“订阅 / 添加到手机桌面”说明：

1. 订阅弹窗同时显示 iPhone/iPad 与 Android 安装步骤，不再只介绍苹果手机。
2. Android 明确说明：Chrome → 右上角 ⋮ → 添加到主屏幕 / 安装应用 → 安装。
3. 根据设备自动显示对应提示；Android 支持 `beforeinstallprompt` 时优先直接弹出安装。
4. 新增 `docs/impactone-add-to-home-screen-guide.pdf` 图文安装说明，可直接从订阅弹窗打开。
5. 其余 V3.11 排版、分享、Skyline、收藏、评论等保持不变。
